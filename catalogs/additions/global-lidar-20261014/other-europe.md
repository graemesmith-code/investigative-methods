# Spain, Italy and Nordic source evidence

Checked 14 October 2026. Selective official-source research; no accounts, payments, outreach or bulk downloads. Evidence grades below describe what was verified, not legal advice. `Repeat-region` means official survey documentation establishes another acquisition over the same named region; a matching tile/header pair has **not** been tested. `Conditional` means rights, access or actual overlap remain unresolved.

## Spain: PNOA / CNIG — recommend for first pilots

**Verified national airborne LAZ archive, published classified clouds, repeat-region evidence and explicit reuse terms.** [First coverage](https://pnoa.ign.es/pnoa-lidar/primera-cobertura), [second coverage](https://pnoa.ign.es/pnoa-lidar/segunda-cobertura) and [third coverage](https://pnoa.ign.es/pnoa-lidar/tercera-cobertura) have detailed regional flight/publication tables. Madrid is a concrete regional repeat: August–December 2010 (0.5 points/m², stated z RMSE 0.4 m), August–September 2016 (1 point/m², stated z RMSE 0.15 m), March–May 2024 (third coverage, 5 points/m²). All three Madrid clouds are documented as published. A journalist could shortlist industrial estates, peripheral development or excavation in this region, then intersect tile footprints. These are regional acquisition windows, not one precise date for every tile; no actual building change or matched three-epoch tile pair was established.

Access: [official product/download guide](https://pnoa.ign.es/pnoa-lidar/productos-a-descarga) links to the CNIG catalogs. [Third LAZ catalog](https://centrodedescargas.cnig.es/CentroDescargas/lidar-tercera-cobertura) supplies 1 km tiles; earlier cycles generally 2 km tiles, with exceptions. [A real Madrid 2016 tile record](https://centrodedescargas.cnig.es/CentroDescargas/detalleArchivo?sec=9425938) identifies `PNOA_2016_MAD_410-4469_ORT-CLA-IRC.LAZ`, 1 point/m² and 16.98 MB. This is metadata evidence, not a downloaded/decoded tile. Catalog browsed publicly; data download completion and automated bulk route not tested. Official catalog says downloads are free; no nationality restriction found. Avoid assuming the catalog's overall 2022–2025 label is acquisition timing: the September 2026 project table records later flights for some regions.

Products: real point clouds, colourised RGB/IRC (third cycle RGBI). Third-cycle NPC01/NPC02/NPC03 are processing/classification stages, **not three acquisition epochs**; some NPC02 products have ongoing class improvements. [Products guide](https://pnoa.ign.es/pnoa-lidar/productos-a-descarga) separately identifies second-cycle 2 m MDS/DSM and third-cycle 0.5 m MDS/DSM, which include buildings/vegetation, versus MDT/DTM interpolated from ground class. Some derivatives remain pending even when raw clouds exist. ETRS89/appropriate UTM on mainland/Balearics/Ceuta/Melilla; REGCAN95/UTM in Canaries; orthometric heights. Exact vertical realization/geoid and per-tile acquisition time require technical metadata checks; do not label unspecified orthometric heights as ellipsoidal.

Rights: [CNIG third catalog's licence/recognition section](https://centrodedescargas.cnig.es/CentroDescargas/lidar-tercera-cobertura) says licence compatible with CC BY 4.0 and references Order FOM/2807/2015. It provides original-product and derivative attribution formulas. For unchanged third-cycle material use `LiDAR-PNOA-cob3 2022-2025 CC-BY 4.0 scne.es`; for a derivative use `Obra derivada de LiDAR-PNOA-cob3 2022-2025 CC-BY 4.0 scne.es` (plus licence link/change indication under applicable terms). Use the exact formula for each earlier product rather than relabelling all epochs as third cycle. [2016 individual record](https://centrodedescargas.cnig.es/CentroDescargas/detalleArchivo?sec=9425938) independently confirms compatible licence and free provision. Publication/redistribution subject to attribution and licence, with no non-commercial-only restriction found.

Methodological risk: density improves tenfold between 2010/2024; sensors, RGB dates, error specifications and classification change. Regrid both epochs to a common defensible resolution; stable-ground alignment and roof/vegetation checks precede any demolition/height/volume claim. Do not confuse newer classification output with new construction.

## Finland: NLS open 0.5 p — useful low-density conditional repeat

[Historical 0.5 p (2008–2019)](https://www.maanmittauslaitos.fi/en/maps-and-spatial-data/datasets-and-interfaces/product-descriptions/laser-scanning-data) covers all Finland and is no longer updated. [Current open 0.5 p](https://www.maanmittauslaitos.fi/en/maps-and-spatial-data/datasets-and-interfaces/product-descriptions/laser-scanning-data-05-p) retains ground **and objects on the ground**, thinned from higher-density capture; LAZ, normally 3 km sheets. Same regional repeat is strongly expected where new coverage overlaps the complete historical archive, but no concrete dated same-footprint pair was verified here. Use [status map](https://tilannekartta.maanmittauslaitos.fi/laserkeilaus) to select and record both acquisitions before promising a pilot.

[Current programme](https://www.maanmittauslaitos.fi/laserkeilaus-ja-ilmakuvaus) now describes a **nine-year** cycle excluding northernmost Lapland, with 20 points/m² from 2026 in the main KALLIO programme and 5 points/m² in separately specified areas; open 0.5 p output remains. These are programme specifications/plans, not proof that a 2026 open tile is already downloadable. [MapSite](https://www.maanmittauslaitos.fi/en/e-services/mapsite) explicitly allows free geospatial downloads without registration; high-density 5 p requires authentication/payment. Requested manual deliveries have processing charges; select free self-service downloads. Foreign users: service available to everyone; no residence restriction found. API Processes/file-service route is listed but API authentication/limits were not tested.

ETRS89/TM35FIN EPSG:3067, N2000 EPSG:3900. Current 0.5 p single-point maximum standard error stated as 10 cm elevation and 45 cm planimetry on unambiguous objects; sparse roof sampling can still obscure small structures. Historical classes include ground/bridges/unclassified; buildings and vegetation are not reliably separately classed throughout. Use all suitable non-noise returns for DSM rather than only ground points.

[NLS open-data licence](https://www.maanmittauslaitos.fi/en/opendata-licence-cc40) is CC BY 4.0: name NLS, dataset(s), and delivery time. [Publication-rights page](https://www.maanmittauslaitos.fi/en/about-nls/organisation/publications-and-brochures/publication-rights) expressly permits open 0.5 p publication under this licence but says 5 p cannot be published/transferred as such or at similar accuracy. **Do not treat visible high-density data or a paid licence as publication permission.** No high-density purchase attempted; new 20 p publication rules not established.

## Denmark: strong actual archive, account barrier for this project

[Current point-cloud download documentation](https://datafordeler.dk/dataoversigt/danmarks-hoejdemodel-dhm/dhm-fildownload-punktsky/) explicitly lists current `Punktsky`, `Punktsky2015`, and `Punktsky2007`: actual archive products, not just a rolling update schedule. Download is LAZ/LAS 1 km tiles grouped into 10 km ZIP blocks via REST API. **Current official route requires a user, IT system and API key/OAuth**; not sampled because no accounts were authorised. A whole 10 km block can be unnecessarily large for a newsroom pilot. Foreign-user eligibility for account creation was not tested; licence is worldwide.

[2007 official catalog record](https://datavejviser.dk/katalog/klimadatastyrelsen/e9b5f4ee-fca8-4ea3-837c-9da7fbef68ea) identifies historical laser-scanned points. [2014–2015 specification](https://dataforsyningen.dk/asset/PDF/produkt_dokumentation/dk_dhm_punktsky_v2_1_aug_2016.pdf) documents nationwide airborne classified LAZ, buildings and bridges, around 4–5 points/m²; horizontal ETRS89/UTM32. [Terrain specification](https://dataforsyningen.dk/asset/PDF/produkt_dokumentation/dk_dhm_terraen_v2_1_aug_2016.pdf) documents 0.4 m terrain grid and DVR90 (EPSG:5799) vertical system. Historical 2007 versus 2015 national coverage establishes repeat at country level; **exact two-date urban tile pair not tested**. Official historical WMS provides [an example around Middelfart/Fredericia/Kolding](https://datafordeler.dk/dataoversigt/danmarks-hoejdemodel-historisk-dhm/dhm-2007-historik-wms/), but rendered WMS images are not numerical point-cloud data.

[Free geographical-data terms, December 2022](https://dataforsyningen.dk/asset/PDF/rettigheder_vilkaar/Vilk%C3%A5r%20for%20brug%20af%20frie%20geografiske%20data.pdf): worldwide free reuse, copying/distribution/publication/modification and commercial use. Attribute authority, dataset and retrieval time/service; make terms available via copy/link; no implied endorsement. Existing PDF names former authority Styrelsen for Dataforsyning og Infrastruktur while current portal names Klimadatastyrelsen: retain exact supplied terms and confirm current issuer/attribution at retrieval. Metadata catalog's own CC0 statement applies to **metadata**, not automatically to scans.

## Norway: promising project archive, verify source type and project rights

[Kartverket access guide](https://www.kartverket.no/api-og-data/terrengdata) says elevation data free by download/API, including original LAZ/ZLAS, GeoTIFF DTM and DOM/DSM; REST metadata/download and OGC WCS/WFS/WMS routes. [Høydedata](https://hoydedata.no/) carries individual projects and metadata, variable density; some partner datasets/services require login. [National data catalog](https://data.norge.no/en/datasets/8c62e33e-76ba-3c00-9db6-3a10e44135bc/hoydedata-laser) warns point clouds can be airborne laser **or image matching**. Filter to laser project lineage; don't count photographic point clouds as lidar. [Current terms](https://www.kartverket.no/api-og-data/vilkar-for-bruk), updated July 2026: Kartverket free products CC BY 4.0 with `© Kartverket`, link when possible; external/partner layers can have separate rights. No concrete repeated laser footprint, acquisition pair, datum/classification equivalence or foreign account restriction verified. Conditional lead, not a top-ranked verified repeat. Do not infer unrestricted reuse from generic catalog `noConditionsApply` when project rights differ.

## Sweden: current cloud open, current API access needs permission

[Forest lidar product](https://www2.lantmateriet.se/en/geodata/our-products/product-list/laser-data-download-forest/) describes 1–2 points/m² airborne classified LAZ, surveys from 2018, SWEREF99 TM EPSG:3006, CC0/no licence fee. Buildings/vegetation remain mostly unclassified; don't discard that class. [May 2026 change notice](https://www.lantmateriet.se/sv/geodata/vara-produkter/Produktnyheter/Geografisk-information/h/) says from 1 June 2026 access moved to STAC API/COPC LAZ, with API permission ordered through Geotorget. No permission/account created or sample fetched. Historical NH 2009–2019 cloud appears in older official pages, but fresh main link redirects to script-only Geotorget while indexed old versions retain paid restrictions. **Historical NH current licence not established.** Do not assume current CC0 forest terms automatically apply to NH archive. Exact overlap, historical access, vertical RH system and restrictions need fresh metadata; conditional reserve only.

## Italy: Trento is better than a national DTM-only search suggests

[Trento official lidar guide](https://www.territorio.provincia.tn.it/portal/server.pt/community/lidar/) lists 2006–2008 survey DSM (1/2 m) and DTM, plus newer PAT 2014 integrated with 2018 flights: raw LAZ, DSM first/last, DBM and DTM via [STEM](https://siat.provincia.tn.it/stem/). These are repeated provincial programmes, **not proof of independent 2014 and 2018 epochs everywhere**; 2018 is a mosaic update. Exact overlap and separate historical retention must be checked. Suitable next pilot: an Adige-valley industrial site/quarry, after tile intersection and permitting context.

[Fresh official RNDT old raw-cloud metadata](https://geodati.gov.it/geoportale/visualizzazione-metadati/scheda-metadati?metadataid=p_TN%3A3203e1b3-5d73-47d8-b04e-9ab27c8538cf) specifies LAZ, CC BY 4.0 and direct [2006](https://siatservices.provincia.tn.it/idt/raster/lidar_2006_pat_laz/) / [2009](https://siatservices.provincia.tn.it/idt/raster/lidar_2009_pat_laz/) routes. 2009 is completion/corrections in selected areas, not a complete second province survey. [RNDT machine-readable lineage](https://geodati.gov.it/geodcat-ap_it/index.php?inputFormat=REST&outputFormat=XML&outputTransformation=geodcatap_it&src=searchText%3DfileIdentifier%3A%22p_TN%3A3203e1b3-5d73-47d8-b04e-9ab27c8538cf%22) specifies orthometric z, first/last returns, minimum ~1.28 points/m² in urban valley type-1 areas and ~0.48 elsewhere; intensity missing from Toposys valley data. Reference described as ETRS89-GRS80 is insufficient to choose complete projected/vertical CRS without file checks.

An [older licence page](https://www.territorio.provincia.tn.it/portal/server.pt/community/lidar/847/licenza_d%27uso/255622) still states CC BY 2.5 Italy, named provincial office/database and link; newer raw metadata explicitly says CC BY 4.0. Preserve retrieval evidence and product-specific terms rather than silently resolving mismatch. Newer DTM/hillshade metadata also declares CC BY 4.0, but a complete newer raw/DSM licence check was not established; conditional repeat pilot. No territorial restriction found; official pages describe public download, no listed fee. Download/index probes and failures are recorded separately.

**Concrete archival overlap found, with an important limitation:** public 2006/2009 directories share 175 filenames. Header-only probes of `dati-grezzi000478_WGS.laz` in both directories establish overlapping XY bounds. The old [2006-product file](https://siatservices.provincia.tn.it/idt/raster/lidar_2006_pat_laz/dati-grezzi000478_WGS.laz) covers approximately X=666000–668000, Y=5126000–5128000; the [2009-product file](https://siatservices.provincia.tn.it/idt/raster/lidar_2009_pat_laz/dati-grezzi000478_WGS.laz) covers only X=667049.36–667999.99, Y=5126000–5126050, a roughly 950 m × 50 m sliver **inside** the earlier extent. Both return LAS headers and different point counts. This verifies actual overlapping archived point files, but metadata describes the newer project as completion/correction, and headers alone do not establish independent full resurvey or precise acquisition times. This is why matching tile names cannot justify claiming a whole 2 km repeated footprint. No built-environment feature or change was identified in this sample.

Additional Italian reserve: [South Tyrol 2004–06 raw coverage metadata](https://geonetwork1.civis.bz.it/geonetwork/geonetwork/api/records/p_bz%3AGeographicalGrids%3ALIDAR-PointCloudCoverage-2006CGR) declares CC0 and no public-access restriction, but tile download/second epoch not verified. [FVG 2017–2020 cloud metadata](https://irdat.regione.fvg.it/consultatore-dati-ambientali-territoriali/detail/irdat/dataset/11647) describes helicopter lidar at 10–16 points/m², detailed building/vegetation classes and guest Eagle download, yet displayed legal fields are blank: **reuse unknown**, not an open-licence recommendation. [Lombardy official archive page](https://www.regione.lombardia.it/ambiente-e-territorio/infrastruttura-dati-territoriali-idt/consultazione-e-distribuzione-delle-foto-aeree-e-dei-rilievi-lidar) explicitly requires a request for most archive materials; excluded from no-outreach pilot. Tuscany's broad catalog is too sparse to establish repeat dates/raw access.

## Small reproducible check and cost ledger

Python stdlib `urllib.request.urlopen` fetched the PNOA second coverage HTML over HTTPS: HTTP 200, 156,086 bytes; HTML table extraction reproduced Madrid's 2016 August–September / density 1 / z RMSE 0.15 record. A first attempt using `requests` failed because the module was absent; reran using stdlib without installing software. No certificate-warning bypass. Small public index/catalog probes are in [access check](evidence/europe-other-access.json): both Trento raw directory indexes HTTP200 and STEM HTML200; CNIG Madrid individual record returned HTTP503 from this execution environment, despite accessible web-indexed official metadata. No claim of a successful Madrid tile download.

Trento header probe: request `Range: bytes=0-374` to [one publicly indexed old raw tile](https://siatservices.provincia.tn.it/idt/raster/lidar_2006_pat_laz/dati-grezzi000001_WGS.laz) returned HTTP206, `Content-Range: bytes 0-374/51543243`. Read exactly 375 bytes: `LASF` signature, LAS1.2, legacy point count 1,840,822 and 0.01 m XYZ coordinate scales. Header file creation date is **not acquisition date**. Header extent is mountainous; no built-site example or actual change derived. Evidence saved in [header check](evidence/trento-header-probe.json); [overlap check](evidence/trento-overlap-probe.json) records index matching and [paired headers](evidence/trento-paired-headers.json) records the two further 375-byte header probes, both HTTP206. Total point-file bytes sampled: 1,125. No full file/point records downloaded or interpreted. Paid external calls: zero. ChatGPT token attribution: not measured/unknown.
