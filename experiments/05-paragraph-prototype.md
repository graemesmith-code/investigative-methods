# 05. Does the full contract paragraph help?

**Question:** Can the original paragraph in a Pentagon contract announcement give a reporter a better reason to read than a headline alone? The Paragraph Lead Test prototype was published on 27 September 2026. No controlled performance comparison is preserved.

## What the source contains

An announcement paragraph can state the work, location, amount and whether an action is an initial award, an option or a modification. It may still omit the earlier award history. A maximum possible value is not the amount actually paid.

## A recipe you can follow

1. Take a small set of announcements and keep each full paragraph, source and date.
2. Describe the possible reporting question in one sentence. Point to the words that prompted it.
3. Check whether the action is a change or something already announced. Keep any missing context explicit.
4. Compare your choices with a simple rule, such as looking for changed work or dates. Record which questions are worth pursuing and how long review takes.

## What happened

Historical publication was verified. The original code revision, exact model question, dated input set and paragraph-level results were not supplied, so the prototype's existence does not show that its ranking helped.

A useful distinction is an **exercised option versus a genuinely new commission**: both may carry large amounts, but they pose different questions. This is an illustration of what a reviewer should check, not a demonstrated finding from the prototype. The later reported 10,000-paragraph run is described in [experiment 06](06-jev-exa.md).

## Cost, limits and the next useful step

Build, hosting, model and review costs are unknown; current live operation is untested. Recover the inputs, exact prompt and outputs, then compare paragraph-only review with the same records plus relevant earlier actions. There is no evidence here that either approach wins.
