# What is complete, what code saved, and what remains expensive

**Complete:** a catalog-level assessment of all 344 descriptions, review of 65 mechanism families, a 70-pair named-identifier audit, and representative reasoning for 12 purpose-selected event/role clusters. **Open:** broader discovery among other compatible pairs, complete availability/history validation, and execution of any substantive investigation. Neither 344 source notes nor 65 mechanism reviews proves coverage of all meaningful source pairs.

The first generator expanded 65 authored mechanisms into 2,535 rows. It retained 1,730 audit rows after 797 substantive rejections and eight deduplications. Fifteen retained rows are now geographically quarantined, leaving 1,715 active conditional candidates. These are alternative source-pair implementations, not 1,715 independently reasoned hypotheses. Final ledgers distinguish raw, active and quarantined counts consistently.

The additional audit uses the catalog's explicitly named ACN, NZBN, CNPJ, UEI, IMO, MMSI, ASN, DOI, ORCID and domain namespaces. It finds 70 unordered pairs sharing a named namespace, of which 45 are outside the original mechanism rules in both directions. The algorithm does not establish actual identity or field availability. Generic company numbers, local record IDs and geometries are not assumed interchangeable. Cluster assessments distinguish useful new formulations from identity support, duplicated upstream data and invalid inference.

Twelve manually selected event/role clusters enumerate 61 distinct directed pair alternatives. One representative per cluster received substantive reasoning; the other alternatives are labeled as enumerated, not individually reviewed. These clusters overlap the named-identifier audit and must not be added to it as an independent coverage total. Five new formulations were justified. No inference of saturation or of a maximum possible test count follows.

## Actual division of work

| Work | Deterministic code | Model reasoning / source reading |
|---|---|---|
| Provenance | Parses SYS/AP blocks, hashes and exact locations | Selects correct source versions and interprets limitations |
| Universe | Enumerates 117,992 ordered pairs and tracks admission | Decides which relationships could be consequential |
| Mechanisms | Expands rules, rejects gated rows, deduplicates and ranks | Authors expectations, ordinary explanations and falsifiers |
| Completeness audit | Finds 70 namespace-sharing pairs and 61 role alternatives | Chooses compatible event/role clusters and rejects weak associations |
| Corrections | Propagates geography/status/access gates across outputs | Detects wrong IDs, misleading geography and invalid legal/measurement assumptions |
| Validation | Runs 28 checks, including saved identifiers and accounting invariants | Determines whether tests cover important mistakes and reads underlying records |

Code saves manually maintaining thousands of rows and repeatedly reconciling counts, identifiers and ranks. It does **not** turn an identifier overlap into a hypothesis or validate a causal/legal claim. `evidence/reproduction-timing.json` records observed local command durations. These are execution timings, not model reasoning time, token consumption, weekly allowance or dollar savings. No speedup factor or monetary saving is estimated without a measured manual baseline.

## Ranking and practical costs

The large inventory has mechanism-level editorial priority plus deterministic linkage and access gates. It is not a pair-specific newsworthiness ranking. `recommended-next-tests.csv` supplies a separately authored nine-item queue with pair-specific consequence, identity confidence, access burden, missing evidence and cheapest next check. Its composite score is reproducible but uncalibrated. A high score means a promising reporting design, not likely wrongdoing.

Public documentation and earlier small samples cost no paid API calls in this run. Credentials, permissions, manual interpretation and historical records can still make execution expensive. Paris MoU storage permission blocks the repeated-defect comparison; OpenAlex full-content access is credentialed and metered, so no free unlimited download is assumed. The source-specific factual-claim tests need exact original text and historical entity attribution. Many attractive spatial comparisons require specialist validation rather than a cheap point overlay.

No token counters or weekly ChatGPT meter were available. The user's earlier 99% report is historical. This work provides **no measured weekly-allowance reduction**. Jev, Exa and paid OpenAI API calls: zero.

## A bounded cheap-model experiment, not performed

Use the existing saved corpus and a low-cost model only after an explicit execution choice/budget. A useful evaluation set is 24 fixed cases: eight identity/namespace traps, eight timing/measurement traps and eight plausible source-specific designs. Include IMO ship/company mismatch, ASN historical staleness, Google-US-mainland noncoverage, the reciprocal trade tuple, retrospective registration, the World Bank text/index date mismatch, duplicate upstream records and a claim with an exact contrary final finding.

Give each case only the two exact source descriptions, the proposed IF/THEN, and the relevant short authoritative excerpt. Ask for: compatible observation units, missing bridge, strongest ordinary explanation, cheapest discriminating check, and retain/defer/reject. Require quoted field names and cited source IDs; prohibit new legal rules and invented availability. A second pass can check the answer against the original source spans rather than generating more variants.

Score critical false admissions separately from fluent prose. Mandatory failures include promoting name-only joins, confusing IMO company and ship IDs, assuming coverage from Global, inferring absence without a denominator, calling a current trial record prospective, or claiming a paid/credentialed route is freely executable. Evaluate novelty by mechanism and falsifier, not wording. Record input/output tokens and actual cost if the selected execution tool exposes them; otherwise report telemetry unavailable. No such cheap-model experiment or new model API call was made here.

The expected opportunity is cheaper first-pass rejection and structured evidence extraction. Final legal interpretation, causal reasoning, document-version judgment and high-consequence editorial review still need stronger review. Whether the cheap model actually saves work remains an empirical question.
