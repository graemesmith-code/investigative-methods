# Generation and verification provenance

This phase follows the user-authorized OFAC-outward discovery task and the parent's explicit continuation: substantively review the remaining 108 omitted descriptions, cover remaining mechanisms, preserve rejected options and avoid paid APIs or bulk investigations. The independent reviewer supplied concrete corrections about Google footprint coverage, route-specific access ranking, identity semantics, saved linkage tests and the distinction between proposed falsifiers and performed checks. The resulting changes are recorded in `corrections.jsonl`.

All prose judgments were authored in the existing model session and preserved in the three review scripts and `assemble_reviews.py`. No external model API, paid search, extra account or subagent was used in this phase. Deterministic Python performs normalization, expansion, scoring, export, bookkeeping and tests. The same model wrote and checked this phase; no independent review of the third checkpoint is claimed.

Original source descriptions and SYS/AP provenance are retained in `sources.jsonl` and `source-manifest.json`. Source-system coverage labels are catalog assertions. Actual geographic overlap, history and access are not certified by those labels or by the `nation()` exclusion heuristic. The Google coverage correction preserves the original assertion and applies a separate evidence overlay. Other products, including Google temporal buildings, require their own coverage checks.

The 205 participating-source entries each state the source-specific limitation most likely to defeat an admitted mechanism. The 108 new omitted-source reviews each state a proposed use or rejection, a named partner, a discriminating alternative and the next check. The prior 31 notes complete the partition. All 65 mechanisms received individual reasoning, but no claim is made that each of their expanded source pairs has been independently evaluated against records.

Official documentation was read selectively, with URLs and summaries in `evidence/documentation.jsonl`. Saved linking responses are copied from the second checkpoint rather than re-queried. Their original request timestamps, response hashes and acquisition log remain in that checkpoint's `evidence/probes.jsonl`. No new data records were fetched in this phase; web documentation reads are not a paid API call. No source-level schema or conditional predicate is promoted to execution success by a passing code test.

The sample-based tests compare actual saved values, including limiting evidence: retrospective registry timing, negative OONI anomaly/confirmation flags, stale RIPE results and World Bank index/text date inconsistency. The IMO and trade-tuple checks are synthetic semantic regression tests through production helpers, clearly distinguished from the three saved linkage checks. Passing them prevents specified implementation mistakes; it does not establish any real sanctioned-vessel match or trade discrepancy.

The automatic inventory score inherits model-authored mechanism priorities and explicit join/access gates. The nine new formulations have separately authored source-specific score dimensions and a deterministic composite. These rankings measure editorial potential and work burden, not likelihood of wrongdoing. Quarantined rows remain auditable and rank below active candidates. Catalog costs are not current price quotes.

No weekly ChatGPT meter or model token telemetry was available. Paid external API calls in all phases of this work remain zero. The historical user report of 99% remaining cannot be updated by inference.
