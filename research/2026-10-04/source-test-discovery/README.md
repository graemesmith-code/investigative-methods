# Investigative tests, starting with sanctions

This longlist is a menu of questions to test, not evidence of wrongdoing. Start with the highest-ranked recipes relevant to your beat, check one underlying record, and stop when the identity, date, field or inference fails.

The early checkpoint contains **79 conditional OFAC source-pair designs** across nine mechanisms. All 344 explicit-field Rabbit descriptions have been normalized with source hashes, exact text spans and SYS/AP identifiers. None of the designs is yet a confirmed executable test. The larger sweep is continuing.

Download [the early bundle](checkpoints/early-checkpoint.zip), or open [the CSV](checkpoints/early-tests.csv). Read the [quality review](checkpoints/early-quality-review.md) before using the rankings. Different source implementations of the same mechanism are alternatives, not independent discoveries.

A strong starting question: if an OFAC-listed vessel has a valid IMO number, do dated port inspections or movements identify activity worth checking? Confirm the identity, applicable restriction, date, port documents and exceptions before drawing a conclusion. A shared name, a ship position or an award action is not a prohibited transaction.

Use tests.csv/JSONL for the full sweep when available. Each row supplies the initial and expected observations, reasoning, interesting outcome, timing/geography, ordinary explanations, disqualifiers, evidence and next cheapest check. Technical audit files sit alongside this guide.

The repository remains private. No paid Jev, Exa or OpenAI API calls are authorized or used. Weekly ChatGPT allowance and model token meters are unavailable; the user's last reported 99% remaining is historical, not a current measurement.
