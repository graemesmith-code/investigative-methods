# Methods, provenance and audit boundaries

The task is source-level test discovery. User-authorized work includes repository commits, downloadable artifacts, public documentation and bounded free samples; it excludes new paid API calls and bulk execution. Initial normalization reads the latest selected Rabbit volumes, not the older duplicate Rabbit2.txt. The original source manifest records paths, hashes, line/byte provenance and SYS/AP IDs.

The existing model session authored 65 mechanisms and source-role memberships, then deterministic code expanded compatible role pairs. Mechanism priorities express potential public consequence. Source assignment and mechanism quality are model judgments, not a learned or calibrated newsworthiness measure. A Cartesian expansion is not additional independent reasoning. The 18 follow-up cards contain new source-specific reasoning and documentary checks; the 31 omission notes are narrower catalog-grounded judgments and should not be mistaken for sampled availability.

The automatic composite ranking remains a triage aid. Identifier confidence measures the proposed linkage route, not actual successful identity resolution. Testability now refuses to upgrade weak identity through documentation alone. Cost is conservative workload/access burden: tier 2 includes manual reconciliation; tier 3 includes known credentials, permission, paid or failed-access barriers. No fully verified cheap automated route is asserted. Documentation status in the candidate inventory is inherited from the initial pass; current bounded findings belong to the separate review cards and evidence ledger, and do not automatically promote all source pairs.

Each review card preserves geography and temporal scope in its operational join/historical scope and evidence requirements. Legal rules are not inferred from matches. Source-specific legal applicability needs authoritative program text and facts; this checkpoint does not mark any sampled action unlawful. Statistical/measurement expectations remain conditional, with uncertainty, coverage, denominators and competing explanations stated explicitly.

Generation provenance: existing ChatGPT model environment, no external generation API, no new Jev/Exa/OpenAI calls, no verified token counter or weekly meter. Prompts consisted of the delegated task (OFAC outward; high consequence; no padding; explicit evidence and falsifiers) and the follow-up review priorities: specialize valuable recipes; verify public docs/small samples; revisit omitted sources; correct ranking, direction and validation defects. Authoring scripts preserve the resulting decisions exactly. No independent model or human review is claimed for this follow-up.

The 12 integration checks exercise production ranking and actual emitted artifacts: counts, provisional identity, authorization burden, corrected F02 direction, unexecuted status, valid source-review references, evidence references, mechanism diversity, bounded samples, omission-depth accounting and evidence hashes. Earlier 14 synthetic inference-helper fixtures did not exercise the generator; they are not evidence that the old production ranking was correct.

Coverage is bounded: 117,992 ordered pairs enumerated by policy, 2,535 mechanism expansions evaluated deterministically. Pair-policy exclusion is not proof that no interesting hypothesis exists. Thirty-one of the 139 omitted descriptions now have explicit substantive notes; 108 still have only catalog triage. Review and refine them before asserting discovery saturation. The 5,000 target remains aspirational, not a quota.

Failed or blocked access observed: original CISA schema HTTP 403; Paris MoU rendered a system error and imposes prior written storage authorization; several IRS web download routes errored before one official synthetic example succeeded; Comtrade API root returned 404 (not a dataset failure). Equasis/Companies House/ENTSOE/EIA authentication or approval requirements were documented without requesting accounts or tokens. Raw GitHub binary download previously returned a client transform error; publication is verified using remote Git blob identity and byte count.
