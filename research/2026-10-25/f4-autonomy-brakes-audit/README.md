# F4: the autonomy brakes audit

**Read [report.md](report.md) first. The proposed “ASIMOV ended, therefore no brakes remain” story is not supported.** Explicit normative work, training tools, human-constraint demonstrations and technical assurance survive, with significant limits. Documented institutional weakening deserves reporting without a universal absence claim.

Research cutoff: **25 October 2026**. This is a public-source investigative safeguards audit. No source outreach, email, paid model inference or operational weapons-development experiment was performed.

## Reproduce

Use Python 3. Standard-library scripts cover the main screen, live verification, financial case summaries and packaging. The supplementary parquet pass uses pyarrow; its version and mirror/row accounting are recorded separately. Obtain the exact authorized input archives identified by hashes in the screening audit, then run the commands in [SCREENING.md](code/SCREENING.md). Raw data/SQLite/cache paths belong in a private workspace, not this repository.

`code/live_verify.py` documents the public USAspending/FPDS endpoints and retains pagination/status/hash records. `code/exa_serial.py` is the only paid search route: serialized durable reservations, conservative uncertain-charge accounting and a persistent stop latch. Official pricing was verified before use. The configured credential is read from the environment and is never written into this package.

Run `python3 code/build_reviewed_cases.py`, the validation script, then `python3 code/package_artifacts.py` after final edits. `SHA256SUMS` hashes every authored member except itself and the two recursive delivery containers; `manifest.json` explains recursion exclusions. The package script byte-compares every embedded member. The bundle's independent hash is reported at delivery.

## Interpret the limits

“Record window overlaps cutoff” means the disclosed performance dates overlap October 25. It does not independently establish ongoing work, remaining funds, deployment or absence of an undisclosed modification. DoD's 90-day contract release delay can hide recent actions; assistance visibility is assessed separately. Acquired archive-window nets can also omit older modifications, so they are not complete award histories or guaranteed lower bounds. Complete pagination means complete returned feeds, not complete knowledge of federal or classified activity. Dollar amounts are obligations or clearly labeled values; subaward rows and secondary categories never add extra prime dollars.

This package changes only this newly requested directory. Publication is verified separately against the remote commit and file hashes; a local commit alone is not publication.
