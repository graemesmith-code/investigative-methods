# Protocol and scope

This review covers 13 October 2016 through 13 October 2026, or an organization's founding through the review date when later. Fifteen named organizations were assigned to five research teams. Work ran in a separate worktree `/workspace/ngo-discovery`, branch `research/ngo-discovery-2026-10-13`, based on repository `main` commit `8557d0d`. No AGENTS.md or applicable local SKILL.md was found in the repository or exposed workspace instruction directories. The Library skill was read for artifact routing; the user's explicit repository destination was preserved. Repository visibility was verified private using authenticated GitHub metadata. Existing worktree `/workspace/investigative-methods` and any Peru files/branch were left alone.

Official publication catalogs, sitemaps and substantial reports/investigations were preferred. General news links, catalogs, out-of-window reports and translation mirrors do not silently become independent substantive reports. Teams record catalog candidates and uncertain dates explicitly. There is no claim to have read every report published over ten years, no statistical sampling claim and no exhaustiveness claim. Transparency International global material and any purposively chosen national chapter material are distinguished.

## Units and stages

- **Discovered**: a URL/link appeared in a sitemap/catalog/search; may be a landing page, news item, mirror or irrelevant page. These are leads, not reports read.
- **Enumerated source record**: a titled potentially relevant report, substantial investigation, methodology or case-study record. Date/type confidence and scope exclusions must remain visible. An eligible confirmed corpus is a subset where date/type are established.
- **Acquired**: underlying text or PDF bytes were returned. Acquisition may use ordinary verified HTTPS or the browser's readable official page. The method and limitations are recorded; a landing page is not the PDF.
- **Fulltext machine-screened**: acquired substantive text was searched/processed with ordinary code. This is not deep reading.
- **Context-screened/read**: an agent examined substantive passages around candidate bottlenecks. Specify if only an excerpt or browser-truncated text was available. A title or search snippet does not qualify.
- **Deeply read**: detailed assessment of method, relevant passage context, caveats and/or appendices with a documented decision. This is necessarily selective.
- **Retained**: a source explicitly grounds an opportunity retained in the final report. Publication counts, source counts and opportunity counts are different units.

Team original stage labels are preserved. Consolidation must not promote fetched documents to read documents. Browser page offsets differ from PDF printed page labels; use the locator actually examined and leave unavailable pagination null. Bytes/hash/page count remain null if not measured. Metadata hashes must not be represented as source-byte hashes.

## Access and evidence

TLS verification remained enabled. HTTP 403, challenge pages, security errors and unavailable PDFs were recorded. No bypass, credentials purchase, paid APIs, private-data access, outreach, regulator request, email or live investigation was performed. A browser-readable official page is a distinct access channel, not proof of automated bulk access. Source caching outside Git is for transient research; repository evidence defaults to metadata, hashes and short justified passages. New excerpts should be at most 25 quoted words per non-lyrical source across the main report; local logs must also avoid unnecessary reproductions. Any longer explicitly licensed metadata must be labelled.

A dataset homepage or documentation page is not a successful data test. The manifest must identify the requested URL/query, retrieval time, status, content type, bytes/hash where available, bounded result and useful fields. A data sample establishes only that sample's availability. It does not establish historical coverage, a complete join, a contradiction, or permission for paid/third-party processing. Failure remains a stop gate.

## Selection

A finalist needs an original dated bottleneck passage; consequential proposition; falsifiable if/then or contradiction test; records on both sides; strong IDs and equivalent definitions/periods; bounded access check; a precise semantic task ordinary code cannot readily generalize; human/code roles; innocent alternative; missing evidence; demonstrated rather than asserted change in feasibility; prior-coverage check; bounded pilot and stop/go/cost assumptions.

Missing any decisive gate means conditional design or rejection. A promising design is not a discovered wrongdoing or scoop. Famous suspects cannot nominate the slice; a transparent data rule must nominate subjects. Aggregate trade discrepancies, name-only sanctions matches, mismatched accounting totals, Lumen's unavailable processing permission and unavailable invoice/leak evidence are excluded.

## Validation and reruns

The root `scripts/consolidate.py` merges team inventories, preserves originals, detects duplicate URL/version records, checks required metadata, derives counts and emits coverage. Team scripts acquire or enumerate their own sources; rerunning them may return different dynamic catalogs or access denials. `scripts/validate.py` checks committed link targets, JSON parseability, manifest references and file hashes without paid calls. Full external link validation is limited to recorded successful requests and recorded denials rather than pretending an inaccessible URL was checked successfully.

Use a fresh checkout and a disposable cache, preserve raw status/errors, and never retry a denied source with evasion techniques. No script reads secret credentials or calls a paid model. Future model budgets require separate authorization.

## Revision to selection criteria

The targeted pass supersedes any initial implication that a method must be new in 2026, a contradiction must already be found, or AI savings must be experimentally demonstrated to retain an opportunity. Pilot-ready now means enough accessible original records and precise comparison rules exist for a modest reproducible interpretation experiment. The plausible semantic companion, ordinary-code/OCR comparator, accuracy/time falsification, innocent alternatives and later evidence gates must be specified. Known agreement/abstention controls support readiness. New-case novelty is a later reporting check; method precedent is an important comparator. Access denials, private evidence, weak identity, incompatible definitions/dates and restricted processing remain decisive. All initial logs are preserved.
