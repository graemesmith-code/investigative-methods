# Reproduction and provenance

All work here is read-only public-source research. Actual paid spend is zero. No emails, outreach or model API requests were made. The inventory is metadata; bulk report bodies remain under `/tmp/ngo-secrecy` and are not committed.

`inventory.jsonl` contains 518 date-eligible landing/source records (299 NRGI, 110 TJN, 109 Open Ownership). Fields distinguish acquisition, literal machine indexing, contextual screening and deeper reading. `counts.json` is the authoritative count manifest. Shared co-authored work is identified so organization totals need not be mistaken for unique works. `nrgi_landing_inventory.jsonl` also includes 151 older publications and five unresolved dates/failures; those are outside the final date-eligible census. `raw_nrgi_sitemap.json` is raw URL discovery and includes all languages and non-publication pages, not a report count.

Reproduction:

1. Fetch NRGI's three public sitemap XML pages at `https://resourcegovernance.org/sitemap.xml?page=1`, `?page=2`, `?page=3`. Parse URL nodes with Python `xml.etree.ElementTree`. Keep English canonical `/publications/` URLs, normalize exact URLs and retain visible publication dates. Sitemap `lastmod` is not a publication date. The checked XML snapshots remain in `/tmp`; the URL metadata is persistent.
2. Run `python census_nrgi.py`, then `python acquire_selected.py`, then `python machine_screen.py`. These scripts use stdlib HTTPS validation and do not suppress errors or retry through an access restriction. `pdftotext -layout` is the sole external parsing command. Site changes may change current counts/hashes; compare results against this dated snapshot. The keyword selector is intentionally a broad triage strategy, not a relevance proof.
3. For TJN and Open Ownership, direct HTTP requests returned 403. Official catalogs and selected public documents were acquired using the platform's authorized web retrieval tool. The platform-returned landing representations were parsed to canonical title/URL/date metadata, not scraped behind a denial. Re-run `web.open` on TJN's `https://taxjustice.net/reports/`, then resolve the 110 decade publication links (catalog link IDs 19–128 at this snapshot). For Open Ownership use `https://www.openownership.org/en/publications/?page=N` for N=1…13, resolve substantive publication card links, then deduplicate canonical URLs. Open Ownership's pagination contained stale duplicated cards; the substring-length selector can miss unusually short cards, a recorded gap. No search snippets are counted as report reading.
4. `machine-screen.jsonl` indexes all 44 distinct acquired NRGI PDF representations from 38 publication works. It records original-report and parsed-text hashes, nonempty status, counts of literal screening terms and per-PDF-page character offsets. This does **not** imply contextual reading. Only the 11 named NRGI works marked in `inventory.jsonl` were contextually screened; only the DRC methods/cases/limitations/codebook had deeper review. TJN/OO's partial web PDF/chapter acquisitions are not passed off as entire-document machine screens.
5. Reproduce the bounded payment-access test with `bounded_access_check.py`. It downloads exact listed public DRC/ESTMA files to `/tmp`, hashes them, checks parseability and records status/errors. It makes no payment comparison and no allegation. The authoritative executed test manifest is `drc_pilot_acquisition.json`. `access_checks.json` includes failed homepage/catalog/API probes, rather than silently dropping them.

Original-language substantive reading included French EITI payment/table identifiers and their English/French company-note equivalents. The NGO census itself is English-only apart from additional PDF language representations linked on selected NRGI publications. This is not exhaustive multilingual organizational coverage.

`findings.md` specifies the parked comparison design and exact failed gates. The separate independent audit in the root annexes supplies actual workbook row checks. No restricted/private external workbook reference was followed. Permanent source URLs rather than search-result snippets provide claimant provenance.
