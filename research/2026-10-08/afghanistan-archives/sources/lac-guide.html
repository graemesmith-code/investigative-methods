How to use the completed access to information requests database

Before making an access to information (ATI) request, look through previously completed requests. This page will help you search what has already been made available.

  Completed Access to information requests database

On this page

  • Before you start
  • Search tips

  • Related links

Before you start

Gather information such as the:

  • Access to information (ATI) request number (from Open Government)
  • Item ID number
  • Record group (RG), file or volume number
  • File title

Search tips

The quickest way to start your search is to enter a keyword in the search bar.

If you don’t find what you’re looking for, use the advanced search options to refine your results and search specific fields.

Search by ATI request number

If you have an ATI request number from Open Government, and Library and Archives Canada (LAC) has released the records in full or in part, you might be able to view or download them from LAC’s ATI database. Use the same format to search (for example, A-2016-00512).

Search by archival reference

Use Collection search to gather information about records of interest, such as:

  • Item ID number
  • RG
  • File or volume number
  • File title, etc.

Use one or multiple fields from the Archival reference option menu to narrow your search. Additional fields allow for more precise searching:

  • If you’re looking for a specific record group (RG), enter “RG” followed by the number (for example, RG12). Do not use hyphens or spaces.
  • If you’re looking for a specific file number, volume, box, etc., enter the exact combination of numbers or numbers and text (for example, ARC-3/1797-12).

Advanced search

Search by keyword

  • All of these words
    Returns only results that contain all your search words.

  • Any of these words
    Returns results that contain at least one of your search words.

  • This exact phrase
    Returns only results that contain the exact words you entered, in the order you entered them.

Enter one or multiple keywords. The search tool will return results from both record titles and document contents.

Use the wildcard search by typing partial words and using “*” to replace the endings. For example, “imm*” will bring up “immigration,” “immigrant” and other words beginning with “imm.”

Searches will only return results in the language you searched in. For example, a search for “Army” will not return French documents that include the French word for "Army" (Armée). To view all the available results, search in each official language.

File title

Use this field to search for keywords that appear only in the file title.

To search through the content of the documents as well, use the Search by keyword options explained above.

Item ID number

If you know the Item ID number, previously labelled as the MIKAN number or dataset identifier, enter the number by itself to find a specific record (for example, 4801550).

Recently uploaded

To view the most recent requests added to the website, select a date range. New requests are uploaded to the website at the end of each month.

Access the records

If you find an ATI request of interest in your search, click on it to view the details page.

From there, you can view the documents in the integrated viewer and use tools such as zoom or full-screen mode for easier navigation. In the Contents section on the left, you can click on Details to view information about the selected thumbnail.

You can also select and download documents from the Release package details section below the viewer.

Save your research with My research

You can save and organize completed access to information requests using My research. This feature allows you to save records, create folders, and easily return to your research later.

My research also brings together saved items from other LAC applications, such as Collection search and Census search, so you can access all your research in one place.

To add a release package to your My research account, click on the folder icon with the plus sign (+) in the Action column.

To use My research, you need a LAC account. For more information, visit About LAC account.

If you can’t find what you’re looking for

This database is updated regularly, and we are working to make more documents available to you. If you can’t find what you’re looking for, you can:

  • Consult Collection search. Some records can be viewed, downloaded or ordered.
  • Check Open Government to see if the record is available and request it.
  • Discuss your research needs with our research support specialists through Ask us a question.
  • Make an ATIP request
