# Exact corpus composition and automation

Report-period labels are not publication dates: for example, the June 2009 issue was released on 15 September 2009, and issue 2 mentions an October 2008 report despite its September catalogue label. No ATI disclosure or declassification event is established for any of these bodies. First-online dates remain unknown.

The bounded follow-up adds **one French counterpart, 69 PDF pages**, stored separately under `followup/`; the original 15-file manifest and totals remain unchanged. Combined PDF holdings are now 16 files / 745 pages. The evaluator’s case-study HTML is a separate source, not the full 2014 evaluation.

Code automated catalogue-link enumeration, bounded serial downloads, byte hashing and exact deduplication, PDF/page-count validation, page-text extraction, lexical candidate retrieval, low-text-page OCR, and French-counterpart discovery/extraction. Assistant analysis selected the ten-page packet, interpreted metrics/translation, evaluated competing explanations and compared prior reporting. Neither automated contradiction detection nor cheap-model novelty performance has been demonstrated. No paid inference ran.
