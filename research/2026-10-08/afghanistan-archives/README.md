# Canada's Afghanistan archives: first access and ingestion pilot

8 October 2026. Private research; English-first. **No verified new story, no newly declassified Afghanistan tranche established, and no paid API calls.** The useful result is a reproducible public baseline and a separately verified route to search LAC release-package metadata. Access to the identified LAC PDF remains blocked, not acquired.

Acquired **15 English PDFs, 676 physical PDF pages, 26,102,498 bytes**, with zero exact file duplicates: all 14 issues linked by the official parliamentary-report catalogue, plus the March 2015 development evaluation. This is a complete enumeration of that catalogue's English report series as observed today, **not** a representative sample of Canada's war records. The evaluation is 153 PDF pages; the reports total 523. No underlying diplomatic cables, military operational files, ATI release packets or inquiry exhibits were acquired. The MPCC final report was fetched separately as HTML for prior-findings checks and is excluded from the PDF totals.

The free retrieval/extraction/discovery code ran in the saved cloud checkout. Files and code are checkpointed in a distinct branch. Nothing schedules or runs indefinitely after this turn. Existing Jev permissions and budgets were not reused; no credentials, purchases, requests to departments, access applications, ATI submissions or outreach were made.

## What the experiment supports

**Go:** targeted acquisition of underlying monitoring/evaluation records cited in the public baseline; a small review of LAC package metadata by date and archival reference; deterministic comparison of metric definitions and claims with source-page verification.

**No-go:** mass ingestion on the premise that millions of newly opened LAC pages concern Afghanistan; treating search hits or ATI summaries as document bodies; calling old published shortcomings a revelation; promoting a contradiction without aligning scope, measurement and chronology.

The next potentially useful question is whether a dated underlying warning reached decision-makers before a materially incompatible public claim. This pilot does not establish that chain. A later evaluation's criticism does not by itself prove earlier knowledge, deception or misconduct.
