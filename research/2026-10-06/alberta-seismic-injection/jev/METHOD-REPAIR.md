# Jev method experiment: original failure and bounded repair

Original immutable control artifacts: `C02-monthly-volume-trap.request.json`, `.response.json`, `pilot-evaluation.json`, and `v1-ledger.json`. The first formulation bundled a conditional question: if shutdown-triggered operations resumed, was authorization unresolved? Jev answered 0.82 despite the packet supplying no pumping or restart evidence. A missing public permission record appears to have overridden the unestablished premise. This is an observed failure hypothesis, not access to the model's reasoning.

Version2 asks three separate literal-evidence questions: pumping after the event, an actual stop/restart sequence, and a supplied matching written consent. Code then gates whether the permission branch is relevant using supplied rule/date/formation/activity/magnitude/distance/detection facts. Model outputs do not determine legal applicability. Unknown or midrange evidence produces an indeterminate gate, not false. All outputs explicitly withhold compliance decisions.

Twelve separately labelled fictional controls cover monthly missingness, lawful restart, explicit continuous pumping, wrong zone/activity/date, magnitude disagreement, unknown consent, immediate stop, Mw substitution, a subthreshold magnitude, and a distance outside5km. Expected labels were saved before calls and excluded from prompts. Exact prompts/responses and all failures remain in `v2/`. At an illustrative0.5 extraction cutoff,34/36 atomic answers matched the fixture labels;10/12 packets matched allthree. This tiny designed sample is not a calibrated accuracy estimate. The0.2–0.8 abstention band was specified in code before the calls.

The repair corrected the original conditional-permission false positive, but missed explicit continuous-pumping evidence in S03 (0.46) and S10 (0.34). It also returned intermediate scores for other clear timing facts. Therefore this model is unsuitable as the sole operational-evidence gate. The raw result is retained even when deterministic safeguards avoid a false legal conclusion. `evaluation-initial-gate.json` preserves the first derived gate that treated abstention as false; `evaluation.json` corrects that to null/indeterminate without further API calls. A null permission relevance is an unresolved premise, not a reason to drop a packet.

No real packet is sent for accusation, compliance, pumping-continuation, or permission inference. A further real-data call may only rank already identified evidence gaps, with every packet deterministically labelled indeterminate and no legal verdict in its schema. Such ranking is an editorial heuristic, not a calibrated probability.
